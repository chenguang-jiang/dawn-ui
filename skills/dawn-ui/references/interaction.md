# 交互、状态与设备适配

本文为 dawn-ui 独立补充。先找当前流程会发生的状态，再选相应规则；不把每个状态都实现成新页面。

## 状态从任务推导

用一行描述一条链：入口 → 用户动作 → 等待 → 可观察结果 → 下一步。对异步链再写失败与恢复；对保存链再写刷新读回；对切换对象再写未保存内容怎样处理。

| 状态 | 页面应该回答 |
| --- | --- |
| 初次为空 | 这里能放什么，怎样创建第一项；有可执行入口 |
| 筛选无结果 | 当前用了哪些条件，怎样清除；不误写为没有任何数据 |
| 等待 | 哪个区域在加载；保留上下文，骨架对应最终结构，避免整个页面闪空 |
| 成功 | 哪个对象发生了什么变化；在对象附近兑现，不能只弹“成功” |
| 失败 | 哪一步失败，输入是否还在，怎样重试；不把服务内部堆栈展示给用户 |
| 离线、只读或权限不足 | 当前能查看与能操作的边界，给可用下一步；隐藏按钮不能充当授权校验 |
| 部分成功 | 哪些完成、哪些失败，可单独重试；不整批声称成功 |
| 陈旧数据或冲突 | 哪份内容发生变化、怎样重新载入或保留草稿；不默默覆盖 |

状态不只用颜色表达。错误、选中、禁用和处理中同时有可读文字或形状区别；必要的动态消息用合适的 live region，避免每次更新都打断读屏。

## 表单

标签常驻，placeholder 只给格式例子。按用户思考顺序分组；可选项明确，必填不要只能靠红星。输入类型、自动填充和手机键盘匹配数据，粘贴与密码管理器保持可用。

在用户完成字段或提交后反馈错误，不刚聚焦就报错。错误贴近字段，说明怎样改，保留已有输入；长表单提交失败时把焦点引到错误摘要或首个错误，并能找到相应字段。单位、时区、币种与格式在输入附近说明。

提交时立即反馈且防止重复动作，但允许用户恢复；只有服务确认后才显示最终成功。乐观更新要能回滚，不能用动画伪造保存。可恢复的删除优先撤销；难以恢复或影响大的删除确认对象、范围和后果，默认焦点避开破坏性动作。

搜索用可取消请求或请求标识丢弃旧响应，避免慢结果覆盖新查询。保留查询、筛选、排序与当前对象；需要分享或刷新恢复时按项目约定放 URL。分页或筛选改变后说明结果数量和选择范围，避免误操作隐藏对象。

## 弹层与焦点

简单菜单用非模态弹层，必须暂时阻断当前任务时才用模态框。弹层靠触发点打开，避免屏幕边缘溢出；滚动和视口变化时更新位置。优先复用项目成熟组件与原生语义，不为样式另写焦点管理系统。

模态框有名称，打开后焦点落到合适内容，Tab 留在框内，Esc 按产品语义关闭；关闭后返回原触发点或其合理后继。背景不可交互。未保存内容的关闭处理与页面返回保持一致，不能用层层确认框代替草稿设计。

按钮用 button，导航用链接，输入有可访问名称。鼠标、键盘和触摸均有可见反馈，不能仅靠 hover 暴露必需操作；焦点环不能被裁切或永久去掉。拖拽、滑动与复杂手势提供按钮或键盘等价路径。

## 响应式是任务重排

断点由内容何时放不下决定。桌面同时比较对象，手机通常一次处理一个对象：侧栏转为导航入口，列表与详情变成前后层级，保留返回位置与筛选。不要把所有桌面栏位硬缩成窄列。

表格优先保留识别字段和主动作；需要跨列比较时用有提示的横向滚动，而不是将数值拆到无法比较的卡片。关键操作不被固定底栏、软键盘和安全区域遮挡；弹层内容长时自身可滚动，关闭和提交仍可到达。

在代表性桌面、窄屏、长文案、200% 浏览器缩放下检查；必要时继续检查更大缩放的重排。正常文字对比度以 4.5:1、大字与关键控件边界以 3:1 为检查基线；触控目标优先舒适的约 44px，密集桌面列表可用留白扩大命中区。数值只是检查线索，不据此声称通过全部无障碍要求。
