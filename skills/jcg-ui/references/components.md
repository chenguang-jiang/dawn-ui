# 组件精修与空间交互

本文为 jcg-ui 独立补充，不提供或复刻 Oil UI Pro 的 19 种卡片代码。根据数据关系选结构，按任务实现，不为了“高级”增加容器。

## 先选容器的职责

| 内容关系 | 优先表达 |
| --- | --- |
| 连续阅读或说明 | 开放排版与分节，不必卡片化 |
| 重复、独立、可选择的对象 | 同构卡片或列表，身份与主动作位置稳定 |
| 跨对象比较同一字段 | 表格或对齐列表，避免每卡布局不同 |
| 一个对象的逐层信息 | 原位展开或同一详情区，不套多层卡片 |
| 必须暂时完成的小任务 | 弹层；长任务改独立页面 |
| 次要上下文与辅助操作 | 侧面板或微型抽屉，保留原对象可辨认 |

单组件精修先确定一个视觉主角和一个主动作；记忆点放在结果发生的那一刻。先把文字基线、图标尺寸、数字对齐、边界与状态一致性做准，再增加材质或光效。

## 卡片原型是信息关系

可以从以下关系起步，而不是换一个圆角：图像主导的内容封面；紧凑的处理队列；带阈值和趋势的指标；前后对照；可选配置；可操作时间线；进度/结果；记录及凭证。只选服务当前数据的关系，卡片内的文字、图表与操作保持可编辑、可访问。

对象可点击且有内部按钮时，避免嵌套链接/按钮。让标题链接承担导航，次级动作各自独立；卡片整体点击若保留，不吞掉文本选择与键盘操作。悬停不能是唯一的发现方式。

## 原位展开与微型抽屉

展开前后维持同一个对象，触发位置、标题和视觉锚点保持连续。先定义收起、展开、加载、失败、关闭与中断状态；打开另一项时明确上一项是否关闭、是否保留输入。

- 原位展开适合补充少量信息；展开改变布局时，邻项顺着补位，焦点和阅读位置不跳。
- 卡片内抽屉适合短编辑或次级选择，主对象仍可辨认；内容过多时升级成正常详情页，不缩小字体硬塞。
- 空间折展只在层级关系值得表达时采用：变换外壳，文字在稳定平面排版，不让正文透视变形。透明度、裁切和层级都要避免隐藏内容仍能被键盘聚焦。
- 返回/关闭恢复原位置与焦点。快速连按、尺寸变化、滚动和中途反向操作时可立即到达稳定终态，不能依赖动画回调才能完成业务状态。
- 减少动态效果时直接切换布局；触摸设备不用悬停倾斜，键盘有等价操作。

## 精修顺序与验收

先真实内容和所有必要状态，再校正字重、基线、内外间距、边框/阴影的层次，最后打磨主操作。不要对每个子元素单独加阴影和动效。

在实际尺寸和 200% 浏览器缩放检查：长标题与大数字、图标与文字的基线、触控区域、焦点环、禁用态、加载失败。录一次打开→操作→关闭，并快速逆向一次；仅有动画设计稿不能声称空间交互已通过。
